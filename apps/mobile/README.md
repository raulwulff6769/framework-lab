# ITles для Android

Приложение открывает мобильный кабинет ITles; режим «Телефон в кабине» использует GPS телефона и передаёт полученные точки веб-приложению для отправки в ITles API. Это эмуляция источника телеметрии, а не проверка на установленной в машине технике. APK собран и проверен статически; запуск на телефоне или эмуляторе в этой сборке не выполнялся.

## Фоновая запись GPS

Нативный модуль `@capgo/background-geolocation` запускает Android foreground service типа `location`; при разрешённых уведомлениях он показывает постоянное уведомление ITles. Связка службы и `android.useLegacyBridge=true` предназначена для продолжения получения GPS при свёрнутом приложении/выключенном экране; плагин рекомендует этот режим моста для работы в фоне дольше пяти минут. Разрешение запрашивается при запуске слежения: разрешите геолокацию (для лучшего результата — точную) и уведомления.

Для этого сценария, когда запись начата из открытого приложения и работает foreground service, разрешение «Разрешить всегда» обычно не требуется; `ACCESS_BACKGROUND_LOCATION` не запрашивается. Системные ограничения батареи и режимы энергосбережения производителя всё же могут приостанавливать службу. Если точки перестали поступать с выключенным экраном, откройте настройки Android → Приложения → ITles → Батарея и выберите режим без ограничений/разрешите фоновую работу (название зависит от телефона). После принудительной остановки приложения запустите его и запись заново.

Нативный модуль передаёт фиксы веб-приложению; запросы к API выполняются веб-слоем. Плагин предупреждает, что Android может ограничивать HTTP-запросы WebView после пяти минут в фоне. Надёжная досылка после потери сети или завершения процесса (очередь и нативная отправка) в этой сборке не реализована и требует отдельной проверки.

## Установка APK

Скопируйте `dist/itles-android.apk` на Android-телефон и откройте файл. Если Android предложит, временно разрешите установку неизвестных приложений для приложения, которым открываете APK (например, «Файлы»), установите ITles и затем отключите это разрешение. Откройте кабинет, войдите в учётную запись и запустите режим «Телефон в кабине»; подтвердите разрешения и оставьте видимым постоянное уведомление во время записи.

## Пересборка

Нужны JDK 17+ (рекомендуется 21) и Android SDK с `platforms;android-36` и `build-tools;36.0.0`. Укажите `JAVA_HOME` и `ANDROID_SDK_ROOT` (по умолчанию `/opt/android-sdk`), затем из корня репозитория выполните:

```sh
apps/mobile/build-apk.sh
```

Скрипт устанавливает зависимости мобильной оболочки по lock-файлу, собирает `platform/dist`, если каталога ещё нет, синхронизирует Capacitor, создаёт release APK, выравнивает и подписывает его. Результат: `apps/mobile/dist/itles-android.apk`. По умолчанию ключ создаётся вне репозитория в `/opt/itles-keystore/itles-release.jks`, пароль — рядом в файле `.jks.password` с правами `0600`. Для другого расположения задайте `ITLES_KEYSTORE`. Сохраните этот ключ и пароль: подписывать последующие версии приложения нужно тем же ключом; не помещайте их в репозиторий и не передавайте пароль третьим лицам.
