## 2. Подходы: источник → способ получения → проверка

1. **Сначала существующий канал.** Запросить у владельца техники модель,
   год, установленный терминал/платформу, доступ к данным и архиву: коннекторы
   `platform/server/connectors/` умеют Wialon, Traccar и ISO 15143-3/AEMP;
   Wialon предполагает токен только на чтение. Реальные права и доступность
   API конкретного заказчика ещё не проверены. Если второй сервер терминала
   разрешён, `gateway/` принимает EGTS, Galileosky, Wialon IPS и Wialon
   Retranslator. Перед выбором порта сверять прошивку и настройки терминала,
   в том числе общий режим протокола у Galileosky; госканал не перенастраивать.
2. **Моточасы и пробег без обещаний «любой CAN».** Эталон — показание панели
   с временем; ЭБУ J1939 SPN 247 (PGN 65253) доступен только если его
   предоставляет данная машина, иногда по активному Request PGN 59904.
   По умолчанию — пассивное чтение; запросы на живой шине только с разрешения
   владельца и проверкой гарантий/электрической совместимости. EGTS передаёт
   *счётчики*, но номер счётчика моточасов задаётся для устройства: это не
   стандартное «поле моточасов». `platform/server/domain/counters.ts`
   калибрует оценки по эталону и помечает метод/время источника. ГНСС-пробег
   рассчитывается с учётом стоянки, ошибок координат, гусениц и поворотной
   платформы (`platform/server/domain/odometry.ts`); в пилоте сравнивать с
   независимым одометром, не полагаться на одну только модель.
3. **Резервные способы.** «Телефон в кабине» передаёт ГНСС, а моточасы по
   вибрации **оценивает**, пока их не скорректируют показания панели. Фото/ввод
   показания — отдельный путь, если нет совместимого ЭБУ или терминала.
   Проверить фоновые ограничения Android/iOS, точность по модели телефона и
   досылку накопленного архива; не называть оценку измерением ЭБУ.
4. **Связь и сохранность.** При отсутствии покрытия использовать архив
   устройства/телефона и досылку; `gateway/` пишет в SQLite до ACK и
   пересылает данные в API с повторными попытками. `platform/` обрабатывает
   повторы и показывает свежесть. Архив конечен, поэтому размер, интервал и
   период отсутствия сети измеряются для конкретного терминала. Спутниковая
   связь/LoRaWAN — варианты только после оценки места и стоимости, не
   стандартные компоненты работающего сервиса.
5. **Масло: сначала различить измеряемые величины.** Штатные сигналы ЭБУ
   могут дать уровень/давление/температуру, но **не** качество масла у каждой
   машины. СУЖ M12 — дискретный сигнализатор, не проценты уровня; Rochester
   T-LL415 — непрерывный уровень, для CAN нужны паспортные PGN/SPN; Poseidon
   Trident — состояние/температура, вода только у QW3100; для Modbus нужны
   карта регистров и проверка доступности. `platform/server/domain/sensors.ts` и
   `gateway/itles_gateway/records.py` поддерживают часть приёма и расчётов,
   включая оценку доливов/расхода на **модельных** данных. Настоящее
   подтверждение: паспорт и электрическая схема → стенд с реальным датчиком
   и маслом → эталонный анализ → согласованный монтаж → полевой тренд.
   Монтаж/закупка до проверки штатных каналов не предполагаются.
6. **Протоколы и утраченное продолжение.** Исследования R1–R8 сверялись с
   ГОСТ/мануалами и исправлялись [фактчеком](factcheck-v2.md). Векторы
   `tests/data/traccar_vectors.json` — пакеты из чужого набора тестов, не
   запись нашего полевого испытания. В прерванном рабочем запуске (B:
   293–339, 517–523) разрабатывали Navtelecom NTCB/FLEX и тесты; **в
   опубликованном Git этих изменений нет**. Поддержка FLEX — задача, не
   свойство текущего шлюза. Не переносить без проверки архивные «сырые»
   заметки или слепо повторять числа из ранних исследований.

Исследования по протоколам, праву, API, связи, харвестерам и маслу с
первоисточниками собраны в [истории проекта](project-history.md),
[фактчеке](factcheck-v2.md) и [диздоке](../design/DESIGN-v2.md).
Ранние оценки доли рынка, стоимости спутникового канала и «у каждого ЭБУ
вещается SPN 247» отвергнуты фактчеком — это не утверждённые требования.

## 4. Имена ключей и границы доступа (не значения)

Архив содержит переданные в чат реквизиты Neon и демонстрационных учётных
записей. **Значения, хосты, логины клиентов и строки подключения намеренно не
выписаны**: этот документ и PR публичны. Ни наличие записи в архиве, ни
находка имени в старом деплое не означает, что ключ сейчас действует.

| Имя / категория | Назначение и где требуется | Действие |

   публичный артефакт либо одобряет обезличивание/удаление, проверяется весь
   доступный Git history. Удаление файла новым коммитом **не** удаляет его
   из старых коммитов или кэшей; переписывание опубликованной истории,
   force-push и последствия для SHA/PR — только после отдельного согласования.
2. **P0 — доступы и проверки GitHub.** Проверить, не действуют ли переданные
   в архиве Neon/демо-реквизиты, безопасно сменить и отозвать их. Владелец
   интеграции отдельно предоставляет GitHub App `workflows`; только тогда
   публиковать `.github/workflows/ci.yml` и проверять **GitHub** checks,
   добавив позже изолированные browser и gateway E2E. Пока нет workflow,
   локальные тесты — не CI. Для Cloudflare повторять D1 только после
   исправления разрешений; Tavily-поиск уже проверен.
3. **P1 — матрица источников на конкретных машинах.** Для первых 5–10 машин
   получить модель/год, паспорт ЭБУ, трекер/прошивку, платный или доступный API,
   образец данных, счётчик панели и условия связи; выбрать для *каждой*
   (a) существующий API, (b) второй адрес/ретрансляцию, (c) телефон,
   (d) показание панели. Приёмка: на каждом примере записаны происхождение
   моточасов/пробега/геоданных, права и погрешность относительно независимого
   эталона; некупленное оборудование — только аргументированный исключительный
   случай.
4. **P1 — изолированный стенд.** Реальный терминал + CAN-стенд/паспорт,
   тестовый API и условия обрыва сети. Повторить пакеты с разбиением,
   повреждением CRC, повторами и длительным офлайном; проверить ACK после
   очереди, показания ЭБУ и панели, свежесть, точность пробега и отключение
   координат **до** сохранения. Для FLEX в отдельном PR: официальная
   спецификация NTCB/FLEX, векторы с происхождением, тесты и сквозной сценарий;
   сейчас использовать EGTS только при поддержке конкретным устройством.
5. **P1 — безопасный preview и ограниченный пилот.** В существующем Vercel
   `itles` сначала привязать репозиторий и **фактическую** базовую ветку,
   отдельную preview-БД с синтетикой; сверить SHA и авторизацию.
   Production-деплой, TCP-шлюз на отдельном сервере и реальные координаты
   требуют разрешения, плана backup/rollback и правовой оценки. В пилоте
   измерить расхождение с панелью, задержку после возврата связи, долю
   потерянных/устаревших точек и предел архива *на каждой модели*, а не
   объявлять модельную точность эксплуатационной.
6. **P2 — масло и надёжность.** Получить от FUCHS утверждённые интервалы и
   параметры масла либо явно сохранить их как настраиваемые ориентиры;
   выбрать доступный датчик по паспортному сигналу и при необходимости
   сделать стенд и независимый лабораторный анализ. Далее нагрузочные
   измерения, мониторинг очереди/БД, резервное копирование с восстановлением,
   RPO/RTO и проверка устройств Android/Windows/iOS. StanForD, кубатура,
   конкретная 1С и лабораторный обмен — отдельные поздние интеграции с
   тестовой средой партнёра, не блокирующие три исходных показателя.

Для шага 1 нужно решение владельца о праве публиковать спорные изображения,
книгу и метаданные; для шагов 3–6 — доступ к выбранным машинам/действующим
терминалам и уполномоченный контакт партнёра. Остальные безопасные
локальные тесты и документацию можно продолжать без доступа к production.
Детальнее об исполнении — [ROADMAP](../ROADMAP.md) и
[операционный runbook](../operations/vercel.md).
